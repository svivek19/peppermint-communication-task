# ShopNow – Product Listing & Cart App

ShopNow is a modern, responsive product listing application built using **React**, **Tailwind CSS**, and **React Router DOM**.  
The project demonstrates core e-commerce features such as product listing, search, filtering, sorting, and cart management.

## ⚙️ Project Setup

### Prerequisites

- Node.js (v16 or above)
- npm

### Steps to run locally

```bash
git clone https://github.com/svivek19/peppermint-communication-task.git
cd peppermint-communication-task
npm install
npm run dev
```
